THREATLINK INTELLIGENCE GATEWAY

System Architecture, Machine Learning Pipeline & Threat Telemetry Specs

Platform Overview & Mission

As cyber threat actors deploy automated, zero-day infrastructure faster than traditional static blocklists can update, everyday users face unprecedented digital risks. This platform combines a high-performance Python Flask backend with a serialized machine learning classifier, real-time threat feeds, and automated URL defanging to deliver instant, actionable security intelligence.

Applied ML & Detection Architecture

Our hybrid defense mechanism processes every targeted link through a rigorous multi-stage telemetry pipeline:

Machine Learning Model:

Trained and serialized on a 38,800 URL dataset, extracting 14 lexical and host features to achieve 97.01% model accuracy.

Shortener & Redirect Resolution:

Unmasks malicious redirect hops and shortener links to expose the true destination endpoint prior to evaluation.

Asynchronous AI Briefings:

Integrates automated AI threat summaries to provide instant contextual explanations and actionable insights.

Model Retraining Feedback Loop:

Users can report false positives or flag zero-day phishing samples directly to log telemetry for continuous evaluation.

3-Level Risk Scoring Framework

To translate complex mathematical probability and feed matches into instant security actions, URLs are categorized into three operational tiers:

Safe / Low Risk

Standard URL syntax, clean lexical features, and verified clean status across security feeds.

Suspicious

Triggered by anomalous structural indicators or mixed signals. Proceed with caution.

Malicious / High Risk

Fired when active threat intelligence or ML models confirm credential harvesting behavior.

SOC Utilities & Data Export

Built with security analysts in mind, the platform includes automated **URL defanging** (converting dangerous links into safe formats like `hxxps://example[.]com`), **JSON report exports** for incident logging, and **live telemetry feeds** tracking total system scans and neutralized threats in real time.
